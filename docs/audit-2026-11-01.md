# Audit — 2026-11-01

Scope: `core-platform/`, `harness/`, `deskbook/`, and how the three behave
together. Method: a cold start after a host reboot, targeted probes (French
briefs, hook wiring, port blocks, security headers), then the full end-to-end
run on the live platform.

**Result after the fixes: `E2E GREEN — 15 steps`, 41 checks; 31 eval cases,
25 / 25 rules proven; 21 harness unit tests; 16 app scenarios.**

## Findings

| # | Pain point | Severity | Fix | Proof |
|---|---|---|---|---|
| 1 | After a host / WSL reboot no container restarts (rootless Podman has no daemon to honour `restart: unless-stopped`), and OpenBao in dev mode comes back **empty** — apps would crash-loop on missing secrets even if restarted. | High | `./up.sh`: core pipeline → harness bucket → every app pipeline, all idempotent. Auto-restart deliberately not enabled: it would restart apps into an empty secret store. | Cold start of 2026-11-01: core pipeline 10/10 PASS on existing volumes; e2e green after it. |
| 2 | French briefs: JavaScript `\b` ignores accented letters, so `santé\b` never matched — **"données de santé" was not refused**; "téléversent", "valider la demande", "répond à partir des documents", "importe un CSV" were missed. | High | `rx()` compiles every criterion with a Unicode word boundary; French stems added to signals; brief-check reads French recurrence / horizon / upload. | 5 French eval cases, including DeskBook in French → same 9 / 10 bill and vetoes; unit test on boundaries. |
| 3 | The guard hook lived only in `<app>/.claude/settings.json`: an agent opened at the repo root (the usual case) had **no hook**, and `cd deskbook && bun add ioredis` from the root was never checked. | Medium | Root `.claude/settings.json` wires the hook; a root-level Bash command is checked against every app it names. | e2e step 10 and a unit test: refused with exit 2. |
| 4 | nginx resolved `deskbook-api` once at start: after an API restart (new IP) or with a second replica, the frontend kept proxying to a dead IP (60 s connect timeout). | Medium | Runtime DNS (`resolver` from the image's template entrypoint, `valid=1s`), `proxy_connect_timeout 1s`. | `C1 stateless`: a session survives a new API process through nginx. |
| 5 | Nothing stopped two apps from taking the same port block. | Low | `plan` refuses a block another app holds; with no `port_block` in the brief it picks the first free one. | Unit test. |
| 6 | An uploaded SVG floor plan was served same-origin without a sandbox. | Low | `Content-Security-Policy: sandbox; default-src 'none'` + `nosniff` on plan downloads. | `R4 upload-plan` asserts the header. |
| 7 | Task 2.1 (data model) was "proven" by `/ready` only. | Low | Proven by the first business scenario that reads and writes the data. | Ledger: `2.1 R1 desk-taken`. |
| 8 | An e2e run left the versioned desired state rewritten (new run ids in `.harness/`). | Low | The e2e snapshots and restores `openspec/` and `.harness/` unless `E2E_ARCHIVE=keep`. | `git status` clean after the run. |

Found earlier and already fixed: OIDC clients created with `expireInHours: 0`
(every token issued expired) — `core-platform/idp/onboard-oidc.sh`.

## Known limits, kept on purpose

- Dev-mode OpenBao, registry without TLS, single-node services: a workshop platform (core README, "limits owned deliberately").
- The rate limiter is per API process (N replicas → N × 30 req/s); a shared one needs Valkey, which D3 refuses — revisit when one replica no longer carries the load.
- The hook needs `bun` on the PATH of the agent's shell: on Windows, run the agent inside WSL. Where it cannot run, the CI `fitness` gate still blocks the merge.
- The witness's SIGTERM probe restarts the API during `reconcile` (≈ 1 s of 502 through nginx).
- The cross-family reviewer stays skipped until a provider key and a `harness` vkey exist; the run report says so.
